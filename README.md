# 2D 수학 턴제 RPG

초등학교 5~6학년 수학 퀴즈를 풀며 싸우는 브라우저용 턴제 RPG입니다.

## 실행

설치할 것은 없습니다. `index.html`을 브라우저로 열면 됩니다.
로컬 서버로 띄우려면:

```bash
python3 -m http.server 8123
```

그다음 http://localhost:8123 을 엽니다. 진행 상황은 브라우저(localStorage)에 저장됩니다.

## 폴더 구조

| 경로 | 내용 |
| --- | --- |
| `js/config.js` | 밸런스 수치 (스킬 포인트, 에너지, 피해 공식, 레벨업 비용·성장률, 몬스터 강화율) |
| `js/data/characters.js` | 캐릭터 4명의 스탯, 고유 스킬, 궁극기, 특성 |
| `js/data/monsters.js` | 몬스터 스탯과 행동 |
| `js/data/stages.js` | 스테이지 1-1 ~ 1-12 구성과 보상 |
| `js/quiz.js` | 수학 퀴즈 생성기 (덧셈/뺄셈, 곱셈, 나눗셈, 분수, 도형) |
| `js/battle.js` | 전투 엔진 (화면과 분리) |
| `js/progress.js` | 저장, 스테이지 해금, 경험치 물약, 레벨업 |
| `js/ui.js` | 화면 (스테이지 선택, 파티·레벨업, 전투, 퀴즈 창) |
| `assets/characters/` | 게임에서 쓰는 캐릭터 일러스트 (`Images/` 원본의 영문 이름 사본) |
| `tests/sim.js` | 퀴즈 검사 + 자동 전투로 스테이지별 승률 확인 |

## 전투 규칙

- 아군 4명 대 몬스터 1~4마리. 매 라운드 살아 있는 유닛이 **속도 순서**로 한 번씩 행동합니다.
- **일반 공격**: 선택한 적에게 공격력 100% 피해 → 자연수 덧셈/뺄셈 퀴즈 정답 시 스킬 포인트 +1
- **고유 스킬**: 스킬 포인트 1 소모 → 캐릭터별 퀴즈 정답 시 추가 효과
- **궁극기**: 에너지가 가득 차면 언제든 예약 가능. 진행 중인 행동이 끝난 뒤, 다음 턴 전에 발동.
  에너지를 모두 소모하고, 이후 캐릭터별 퀴즈 정답 시 소모량의 30%를 돌려받음
- 스킬 포인트는 파티 공용 (시작 3, 최대 5)
- 피해 = 공격력 × 계수 × 300 / (300 + 방어력)
- 에너지: 전투 시작 50%, 일반 공격 +20, 고유 스킬 +30, 피격 +10

| 캐릭터 | 역할 | 퀴즈 | 고유 스킬 | 궁극기 | 특성 |
| --- | --- | --- | --- | --- | --- |
| 카가리 | 단일 딜러 | 자연수 곱셈 | 단일 200% (정답 시 300%) | 단일 450% | HP 50% 이하 적에게 피해 +25% |
| 아쿠아마린 | 광역 딜러 | 분수 덧셈/뺄셈 | 전체 110% (정답 시 먼저 적 방어력 -30%, 2턴) | 전체 250% | 적 3명 이상 공격 시 피해 +20% |
| 프리시아 | 힐러 | 자연수 나눗셈 | 가장 다친 아군 250% 회복 (정답 시 나머지 100%) | 전체 300% 회복 | HP 30% 이하 아군 회복량 +30% |
| 히나 | 서포터 | 도형 둘레/넓이 | 전체 공격력 +20% (정답 시 +35%), 2턴 | 전체 공격력 +40% 3턴, SP +1 | 전투 시작 시 SP +1 |

| 몬스터 | 행동 |
| --- | --- |
| 슬라임 | 매 턴 무작위 아군 2명에게 공격력 100% |
| 갑옷 슬라임 | 무작위 아군 1명에게 공격력 100%. 체력·방어력 높음 |

## 성장

- 스테이지를 클리어할 때마다 경험치 물약을 얻습니다 (다시 클리어해도 획득).
- 1-2를 클리어하면 레벨업이 열립니다. 최대 20레벨.
- 레벨 L → L+1 비용: `1 + floor(L / 3)` 개. 레벨당 체력·공격력 +8%, 방어력 +6% (기본 스탯 기준)

## 밸런스 확인

```bash
node tests/sim.js 0.8
```

퀴즈 정답률 80%를 가정하고 레벨별 승률을 출력합니다.
